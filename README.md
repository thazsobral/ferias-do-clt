# 🌴 Simulador e Planejador Financeiro de Férias CLT

Ferramenta web leve e responsiva desenvolvida para ajudar trabalhadores CLT a planejarem suas finanças durante o período de férias, organizando o fluxo de caixa e protegendo o orçamento mensal contra o contracheque reduzido do mês seguinte.

## 🚀 Tecnologias Utilizadas

* **HTML5**
* **Tailwind CSS** (via CDN)
* **JavaScript** (Vanilla, estruturado de forma modular e comentada)

## ✨ Principais Funcionalidades

* **Cálculo Proporcional:** Baseado no salário base nominal, dias de férias e dias de abono pecuniário (venda), contemplando o terço constitucional.
* **Descontos Inteligentes:** Estimativa automática de encargos (INSS/IRRF) para o cenário de 2026, com opção de inserção manual.
* **Distribuição Estratégica do Líquido:** O dinheiro é dividido automaticamente em três fatias essenciais:
  1. **Lazer / Viagem:** Proveniente dos dias vendidos (abono).
  2. **Reserva do Dia 15:** Garante o compromisso do meio do mês (ausência de "vale").
  3. **Reposição do Próximo Mês:** Compensa o contracheque menor do mês seguinte.

## 🛠️ Como Usar

1. Faça o download ou clone este repositório.
2. Abra o arquivo `.html` principal diretamente em qualquer navegador moderno.
3. Insira os dados do seu contracheque e visualize o planejamento financeiro gerado em tempo real.
